## Preview Fix: blank page caused by stale dev server on port 5173

- **Symptom:** User reported preview opened to a blank page.
- **Root cause:** Yesterday's vite dev server process (PID 26156) was still alive on port 5173 but stale/broken (HTML served, module pipeline dead → white screen). New dev server kept falling through to 5175 because 5173/5174 were occupied (4 total stale node/vite processes found: 26156, 12784, 35116, 2232).
- **Fix:** Stopped background task, killed all 4 stale node processes via `Stop-Process -Force`, verified ports free, restarted with `npm run dev -- --port 5173 --strictPort` (background task xTaj3M), verified `main.tsx` + `App.tsx` compile (200), reopened preview on http://localhost:5173.
- **Lesson:** When previewing a Vite app, always check the actual port in the dev server log — vite auto-increments ports when occupied, and stale servers from previous sessions can serve broken pages on the "expected" port. Use `--strictPort` to pin.
